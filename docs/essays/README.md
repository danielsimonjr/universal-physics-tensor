# docs/essays — Speculative Application Essays

Companion folder for the highly-speculative APPLICATION/RISK essay content
relocated out of the core formal specification on 2026-06-11, per
`docs/planning/v0.8.0-Improvement-Plan.md` G-4 (essay relegation).

| File | Relocated from | Content |
|---|---|---|
| [Part-V-Applications.md](Part-V-Applications.md) | `docs/specification/Part-V.md` §§XXI–XXII | Technology transfer / medical applications; existential-risk analysis and ethics guidelines |
| [Part-VI-Applications.md](Part-VI-Applications.md) | `docs/specification/Part-VI.md` §§XXVIII–XXX | Quantum internet, excised consciousness engineering, cosmic engineering; emergency protocols; international governance |

These essays are exploratory thought experiments about what far-future
applications *might* look like *if* the framework's speculative bridge
equations were correct. They are **not** engineering specifications,
predictions, operational protocols, or (in the medical sections) clinical
guidance — every caveat from the originals is preserved verbatim. The core
spec remains [`docs/specification/`](../specification/README.md); stub
headings there record what moved and preserve section numbering.
