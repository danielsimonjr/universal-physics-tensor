# UPT v0.6.0 — Documentation Integrity Review (Master Report)

**Generated**: 2026-05-20.
**Method**: 8-batch parallel review by an opus+sonnet agent team, governed by the
`rlm` skill (partition ~60 docs into file-disjoint batches; aggregate without

## Executive Summary — the honest headline

**The v0.6.0 release work did not introduce documentation hallucinations.**
Batch A (the 6 v0.6.0-cycle docs — Design, Plan, both vet-findings,
Brainstorm, pc-1.5 finding) found **0 CRITICAL, 0 fabrications**: all cited
SHAs resolve, all 6 bridge IDs/descriptions are correct, the Kretschmann
`K(r_s)` formula is sound, test counts verify. The user's concern — that
subagent-written v0.6.0 docs carried fabrications like the `todo.md` bridge
mislabel — is **not borne out for the cycle docs**. (That `todo.md` mislabel
was a real fabrication, but it was caught and fixed in commit `50c231b`
before this review.)

**The real problem is accumulated staleness.** The long-lived current-state
docs were not updated across v0.4.6 → v0.5.0 → v0.5.1 → v0.6.0:

- **`README.md` is six releases stale** — still declares "Current Version:
  v0.4.5" and lists shipped v0.5.0 features as future work. (CRITICAL)
- **Five core architecture docs** (`API.md`, `ARCHITECTURE.md`,
  `OVERVIEW.md`, `COMPONENTS.md`, `DATAFLOW.md`) are stamped **v0.4.0 /
  2026-05-16** — two minor releases behind. They omit the entire curvature
  layer, GL4, the Killing/Einstein/Weyl/Kretschmann machinery, and the
  `CurvatureCompositeNode` factory. `COMPONENTS.md` actively instructs the
  reader *not* to extract a factory that has already been extracted.
- **Three architecture docs** (`DEPENDENCY_GRAPH.md`, `TEST_COVERAGE.md`,
  `unused-analysis.md`) are v0.5.0-era — one release stale; their file/export
  counts and coverage figures are computed off a 79-file snapshot (actual
  `src` is **93** `.ts` files).
- **The formal specification** (`Part-I..VIII`) is internally careful but
  drifted: it states the catalog as **40 bridges** throughout (actual: 42,
  IDs 11–52), carries stale BE-36/BE-37 formulations, and its grammar parts
  (VII/VIII) predate the v0.4.0+ connection/curvature AST node family.
- **All three sub-READMEs** omit every v0.6.0 addition.

**Total: 63 reconciled findings** — 7 CRITICAL, 30 HIGH, 17 MEDIUM, 9 LOW
(after striking 6 false-alarms and 1 agent-error; see §Reconciliation).

This is **documentation debt, not a v0.6.0 defect**. None of it blocks the
npm publish or affects shipped code behavior — but `README.md` and the
architecture docs actively mislead a new reader about what the library is.
