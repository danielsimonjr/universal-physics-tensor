## Overview

Four bridges in the v0.6.0 deferred list each need a NEW AST
primitive to encode their structural content:

| Bridge | What's missing | Required primitive |
|---|---|---|
| BE-13 (Einstein-trace) | Structural tensor-trace operator | `TensorTraceNode` |
| BE-19 (quantum-bounce) | Modified Friedmann predicate | `FriedmannEquationNode` |
| BE-39 (asymptotic safety) | β-function / RG-flow operator | `BetaFunctionNode` |
| BE-50 (Wheeler-Feynman) | Gauge-field ratio + time-symmetry | `GaugeFieldRatioNode` + `TimeSymmetryPredicateNode` |

Each follows the v0.6.1 + v0.7 discriminated-union pattern
established by `EinsteinFieldEquationNode` and (newly)
`KleinGordonEquationNode`. None require a parametric generic
(rejected as v0.5.0-ricci-slot-trap anti-pattern in
`docs/architecture/v0.7-tensor-equation-node-design-note.md`).

## BE-13 — `TensorTraceNode` for the Einstein trace

### Current encoding

`R = 4Λ − (8πG/c⁴)T` is encoded as a scalar relation where `T`
is a stub `sym('T_trace', ENERGY_DENSITY_DIM)`. The trace
operation `T = T^μ_μ = g^μν T_μν` is implicit (the symbol just
asserts its dimension).

### Proposed primitive

```ts
interface TensorTraceNode {
  readonly kind: 'tensor-trace';
  readonly tensor: TensorSymbolNode | StressEnergyTensorNode | ...;
  readonly metric: MetricTensorNode;  // g^μν for the contraction
}
```

`validateTensorTrace` would:
1. Check `tensor` is rank-2 lower-lower
2. Check `metric` is rank-2 upper-upper inverse-metric form
3. Return scalar result with dim = tensor.componentDim

### Application to BE-13

Re-encode `BE13_EINSTEIN_TRACE_RHS`'s `T_trace` stub as
`{ kind: 'tensor-trace', tensor: <T_μν node>, metric: <g^μν node> }`.
This makes the structural relationship to `EinsteinFieldEquationNode`
explicit: the trace of the rank-2 field equation IS BE-13's RHS.

### Scope

~60 LOC for `TensorTraceNode` + validator + tests; ~30 LOC change
in BE-13 encoding + test updates. **One focused session.**

## BE-19 — `FriedmannEquationNode` for modified-Friedmann predicates

### Current state

BE-19's LQC modified Friedmann `H² = (8πG/3)ρ(1 − ρ/ρ_crit)` is
encoded as a scalar expression. No structural recognition that
it's a *cosmological-field-equation* class.

### Proposed primitive

```ts
interface FriedmannEquationNode {
  readonly kind: 'friedmann-equation';
  readonly hubble: ScalarFieldNode;       // H or H²
  readonly density: ScalarFieldNode;       // ρ
  readonly correction: ScalarExprNode | null;  // (1 − ρ/ρ_crit), null for canonical
  readonly coupling: 'friedmann';          // tag for 8πG/3
  readonly variant: 'classical' | 'lqc' | 'brane' | ...;
}
```

Discriminator-tagged variants would let v0.8+ add BE-NN brane
cosmology / DGP gravity / dRGT massive gravity etc. as additional
variants.

### Scope

~100 LOC primitive + validator + tests; ~40 LOC BE-19 re-encoding.
Larger than BE-13 because Friedmann has more structural variants
to type. Two focused sessions if combined with BE-19 test rewrite.

## BE-39 — `BetaFunctionNode` for RG-flow primitives

### Current state

Asymptotic safety's β-functions `β_g(g, λ) = ag² + bgλ + ...` are
dimensionless polynomial relations in dimensionless RG couplings.
Currently encoded as `op`-tree expressions with all-dimensionless
symbols. The structural fact "this is an RG-flow equation, not a
generic algebraic relation" is invisible to the AST.

### Proposed primitive

```ts
interface RGCouplingNode {
  readonly kind: 'rg-coupling';
  readonly name: string;
  // All dimensionless by RG-discipline; no dim field needed.
}

interface BetaFunctionNode {
  readonly kind: 'beta-function';
  readonly couplings: ReadonlyArray<RGCouplingNode>;  // (g, λ, ...) the flow direction
  readonly target: RGCouplingNode;                     // which coupling's beta function
  readonly polynomialExpansion: ExprNode;              // the actual β(couplings)
  readonly fixedPoint?: ReadonlyArray<number>;         // optional UV/IR-fixed-point pin
}
```

`validateBetaFunction` would:
1. Check `polynomialExpansion` reduces to dimensionless
2. Check fixed-point values lie in the coupling parameter space
3. Check `target` is in the `couplings` list

### Application to BE-39

Re-encode the asymptotic-safety β-functions as
`BetaFunctionNode` instances per coupling. The structural fact
that they collectively define a flow with a UV-fixed-point
becomes explicit at the type level.

### Scope

~150 LOC primitive + validators + tests; ~80 LOC BE-39 re-encoding.
**Two focused sessions.** Multi-coupling flow is the highest-
complexity primitive of the four; would also unlock future RG
work on other BE entries.

## BE-50 — `GaugeFieldRatioNode` + `TimeSymmetryPredicateNode`

### Current state

Wheeler-Feynman's dimensionless retarded/advanced gauge-field
ratio (the time-symmetric absorber relation) is encoded as a
generic scalar. The "this is a time-symmetry predicate, not a
generic dimensionless ratio" is invisible.

### Proposed primitives (two)

```ts
interface GaugeFieldNode {
  readonly kind: 'gauge-field';
  readonly name: string;
  readonly arrowOfTime: 'retarded' | 'advanced' | 'symmetric';
}

interface TimeSymmetryPredicateNode {
  readonly kind: 'time-symmetry-predicate';
  readonly retarded: GaugeFieldNode;
  readonly advanced: GaugeFieldNode;
  // The predicate: |retarded - advanced| / |retarded + advanced| ≤ epsilon
  readonly epsilon: number;
}
```

This makes the "two-arrow-of-time" structure explicit.
`TimeSymmetryPredicateNode` is a sibling of
`EinsteinFieldEquationNode` shape-wise (predicate, not value).

### Application to BE-50

The current dimensionless residual scalar becomes a
`TimeSymmetryPredicateNode` whose `epsilon` documents the
allowable deviation. The discriminator makes "this is a
time-symmetry test" explicit.

### Scope

~120 LOC across two primitives + validators + tests; ~50 LOC
BE-50 re-encoding. **One focused session** (the second primitive
is small).

## Recommended order of implementation

If all four ship across follow-up sessions:

1. **BE-13 first** (`TensorTraceNode`) — smallest scope; the
   existing EinsteinFieldEquationNode infrastructure mostly
   covers what TensorTrace needs. Cleanest single-session win.
2. **BE-39 second** (`BetaFunctionNode`) — highest-leverage; the
   RG-flow infrastructure unlocks future RG-related BE entries.
3. **BE-50 third** (`GaugeFieldRatioNode` +
   `TimeSymmetryPredicateNode`) — sibling to existing
   EinsteinFieldEquationNode pattern; clean type-design exercise.
4. **BE-19 last** (`FriedmannEquationNode`) — largest variant
   space; benefit from the patterns established in the prior
   three.

Each lands as an independent commit with no cross-dependencies.

## Honest scope note

This is design work for follow-up sessions. The user-approved
"AST for BE-13/19/39/50" gets ONE demonstrator (Klein-Gordon)
shipped now + four per-bridge design proposals documented for
later. Implementing all four BE-X re-encodings in a single
session is ~430 LOC of new primitives + ~200 LOC of re-encoding
+ test pin updates — beyond the practical scope of a single
follow-up batch.
