## 0. Plan-execution discipline

- **Worktree fork-point preamble** (Decision #4): every agent brief
  STARTS with the canonical preamble:
  ```
  git fetch origin claude/changelog-todo-sync-9PdMg
  git status --porcelain | grep -q . && {
    echo "FATAL: worktree has uncommitted changes; aborting"; exit 1; }
  test "$(git rev-parse HEAD)" = "$(git rev-parse origin/claude/changelog-todo-sync-9PdMg)" \
    || git reset --hard origin/claude/changelog-todo-sync-9PdMg
  ```
- **Dispatch model** (Decision #9 + Eve E9): default is DIRECT EXECUTION
  on the main branch OR a single serial subagent. Parallel-subagent
  dispatch is the EXCEPTION; only invoke when work is genuinely file-
  disjoint AND time-pressured.
- **Adam+Eve dispatch** (Decision #9): vet pairs always SERIAL — Adam
  first, commit + push, then Eve on the post-Adam HEAD.
- **Honest-claude framing**: every commit message that deviates from the
  plan documents the deviation (per CLAUDE.md "Honest deviation goes in
  the commit message").
- **Stale-carry-forward discipline** (v0.7 lesson): every task's
  prerequisite step re-runs the producing grep / measurement at HEAD
  before treating the design's number as ground truth.
