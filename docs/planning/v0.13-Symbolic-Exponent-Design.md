# v0.13 — Symbolic Exponents on a Dimensionless Base (Design Note)

A bounded extension to the `^` ExprNode arm: allow a NON-literal (input-dependent)
exponent **when the base is dimensionless**. Sound because
`dimensionless^(anything dimensionless) = dimensionless`, so the result dimension
is statically inferable without knowing the exponent's value. Unblocks faithful
encoding of scaling-law bridges (Hertz-Millis `(T/T₀)^(−1/z)`, RG flows) whose
powers are input critical exponents.

## Motivation (grounded)

- The `^` arm currently requires a **numeric-literal** exponent
  (`validator.ts` ~line 387; `expr-eval.ts` `^`). BE-33 (Hertz-Millis) already
  documents this as a limitation and WORKS AROUND it by pinning `z=1`:
  `BE33_HERTZ_MILLIS_RHS` encodes `(T/T₀)^(−1)` with a literal `sym('-1')`, with
  a docstring noting "The AST `^` op requires a literal-numeric exponent."
- This extension lets such bridges carry a *faithful* `symbolic` form
  (`(T/T₀)^(−1/z)`, z an input) on the composition edge — dimensionally
  validated and numerically evaluable against the real evaluator. It is the
  bounded grammar piece flagged in `docs/research/Orphan-Connector-Analysis.md`.
- It does NOT make CI-1 checkable (CI-1 is an over-determination, not a
  composition — see the corrected research-note section). Independent value.

## The change

### `validator.ts` `^` arm

After the existing arity guard + base probe + tensor-base rejection, classify the
exponent:

- **Literal** (`expNode.kind === 'symbol' && Number.isFinite(Number(name))`):
  unchanged — `return power(baseDim, Number(name))`. Covers `c^3`, `lP^2`, etc.,
  AND a dimensionful base (the only case literal exponents are needed for).
- **Non-literal**, and `baseDim` is **dimensionless**: NEW. Infer the exponent
  (forwarding its violations); reject a tensor exponent (`TensorInScalarOpError`);
  require the exponent's inferred dim to be DIMENSIONLESS (else a violation);
  `return DIMENSIONLESS`.
- **Non-literal**, and `baseDim` is **dimensionful**: violation — preserve the
  existing message shape (note matches `/\^ exponent must be/`, `expected =
  DIMENSIONLESS`, `actual =` the throwaway-probed exponent dim). This keeps the
  pinned test `validator.test.ts:206` green.

### `expr-eval.ts` `^` arm

Relax to evaluate the exponent subtree generally:
`return finite(Math.pow(evalExpr(base), evalExpr(exponent)), node)` (keep the
2-arg guard). A literal `sym('3')` resolves to `3` via the existing numeric-leaf
path, so Case-1 behavior is byte-identical; a variable exponent now evaluates.

### No change to simplify

`renderGensym` (expr-simplify) already throws `Unsupported` on a non-literal
exponent → `simplifyExpr` gracefully no-ops on variable-exponent forms. That is
acceptable (BE-33's form need not simplify); documented.

## Demonstration (the real consumer)

Add `be33Edge.symbolic` = the faithful `xi_0 · (T/T_0)^(−1/dynamic-exponent-z)`
(leaves: reference-correlation-length, temperature, reference-temperature,
dynamic-exponent-z; all the source quantities), dim-validated to `[length]` and
drift-guarded against `evaluateHertzMillis` (which uses the real z). This proves
the extension end-to-end on a real bridge. (BE-33 composes with nothing — it is a
demonstration of the faithful encoding + grammar, not a composition enabler. The
catalog AST `BE33_HERTZ_MILLIS_RHS` is left UNTOUCHED to avoid disturbing the
dimensional-signature round-trip.)

## Regression surface (the load-bearing tests)

- `validator.test.ts:206` — dimensionful base + non-literal exponent must still
  violate with the same message shape. PRESERVED by the dimensionful branch.
- `validator.test.ts:144/153` — `^` arity guards. PRESERVED.
- All literal-exponent encodings (`c^2`, `g^2`, BE-33's pinned `^(-1)`,
  rg-flow `g^2/g^3`, the symbolic CT-1 `c^3`) → Case 1, byte-identical.
- No test pins the old "not a finite number" symbol-exponent path (grep-verified
  empty); that path is subsumed by the non-literal logic.
- evalExpr: `c^3` and all literal symbolic forms evaluate identically.

## Test plan

- Validator: dimensionless base + dimensionless variable exponent → ok, dim
  DIMENSIONLESS; dimensionless base · ξ₀ → length; dimensionful base + variable
  exponent → violation (test 206 shape); dimensionless base + **dimensionful**
  exponent → violation ("exponent must be dimensionless"); tensor exponent →
  throws.
- evalExpr: variable exponent evaluates (`(a/b)^(c)` matches `Math.pow`).
- BE-33 faithful symbolic form: validates `[length]` + drift-guarded vs
  `evaluateHertzMillis` over probes spanning z ≠ 1.
- simplify: be33Edge.symbolic → graceful no-op (variable exponent).

## Adam vet — r2 revisions applied

Adam verdict: YELLOW. The soundness core holds; the following are binding (all
factual premises grep-verified):

- **(A-1) Exact note strings + branch order.** Classification: `isLiteralExp =
  expNode.kind === 'symbol' && Number.isFinite(Number(expNode.name))`. Order:
  arity guard → base probe → base-tensor reject (unchanged) → if `isLiteralExp`
  `return power(baseDim, Number(name))` → else the non-literal branches below.
  The **dimensionful-base** non-literal branch keeps the existing message
  `'^ exponent must be a numeric literal symbol unless the base is
  dimensionless'` (matches the pinned `/\^ exponent must be/`, test 206) and
  still throwaway-probes the exponent to set `actual` (= LENGTH for 206),
  `expected = DIMENSIONLESS`, returns null.
- **(A-2, soundness) Tensor-exponent check.** The new **dimensionless-base**
  branch infers the exponent via `inferArgLocal(expNode, ctx, 'args[1]')` and
  MUST then `if (expProbe.freeIndices.size > 0) throw new
  TensorInScalarOpError('^')` — exactly as the base does — before any dim
  check. (`inferArgLocal` does not reject tensors itself.)
- **(A-3, regression) Null short-circuit.** In the dimensionless-base branch,
  if `expProbe.dim === null` → `return null` (short-circuit, matching the base
  guard), NOT DIMENSIONLESS. Only after a clean exponent inference: if
  `!equals(expProbe.dim, DIMENSIONLESS)` push one violation `'^ exponent must
  be dimensionless'` (expected DIMENSIONLESS, actual = expProbe.dim) and
  `return null`; else `return DIMENSIONLESS`. (Pushing a violation + returning
  null is the established pattern; never return DIMENSIONLESS while a child
  failed.)
- **(A-6) evalExpr relaxation.** Keep the 2-arg guard and the `finite(...)`
  wrapper; body becomes `return finite(Math.pow(evalExpr(node.args[0], values),
  evalExpr(node.args[1], values)), node)`. Grep-verified: NO test pins the old
  `expr-eval.ts` `^`-exponent message. `evalExpr(sym('3'))` → `3` (resolveLeaf
  numeric path), so literal behavior is byte-identical.
- **(A-7) Drift-guard wiring.** `SYMBOLIC_EDGES` is hand-curated — add the row
  `{ edge: be33Edge, probe: { 'reference-correlation-length': 1e-9,
  'temperature': 300, 'reference-temperature': 100, 'static-exponent-nu': 0.63,
  'dynamic-exponent-z': 2 } }`. `static-exponent-nu` is REQUIRED (the edge's
  domain predicate + `evaluate` use it) even though the symbolic form omits it;
  `evalExpr` ignores the extra key. **`z = 2 ≠ 1`** is essential — it actually
  exercises the variable exponent (z=1 degenerates to the old literal case).
- **(A-8/A-9) Pin the exponent node + leaf name + precondition.**
  `be33Edge.symbolic` = `xi_0 · (T/T_0)^(−1/z)` with the exponent node
  `op '/' [ sym('-1', DIMENSIONLESS), sym('dynamic-exponent-z', DIMENSIONLESS) ]`
  — leaf name `dynamic-exponent-z` (the graph quantity name, NOT `z`). Grep-
  verified precondition: `dynamicExponentZQ.dim === DIMENSIONLESS` and
  `staticExponentNuQ.dim === DIMENSIONLESS` (both all-zeros). Leaves:
  reference-correlation-length, temperature, reference-temperature,
  dynamic-exponent-z.
- **(A-10) simplify** is correctly a graceful no-op (renderGensym's `^` throws
  Unsupported on the non-literal exponent). Unchanged.

The full BE-33 symbolic form:
`op '*' [ sym('reference-correlation-length', LENGTH),
  op '^' [ op '/' [sym('temperature', TEMPERATURE), sym('reference-temperature', TEMPERATURE)],
           op '/' [sym('-1', DIMENSIONLESS), sym('dynamic-exponent-z', DIMENSIONLESS)] ] ]`.
Dim: LENGTH · (Θ/Θ)^(dimensionless) = LENGTH · DIMENSIONLESS = LENGTH. ✓
