## 2. Pre-registered composition targets (P-3 — committed before code)

**CT-1 — "Erasure cost at the horizon" (realizes Part-IX C4).**
Compose BE-42 (Hawking temperature, `M → T_H`) with BE-16 (Landauer,
`T → E_min`) through the shared quantity *temperature*:

    E_min(M) = k_B · T_H(M) · ln 2 = ℏc³ ln2 / (8πGM)

- Junction: the quantity identification "the Hawking temperature IS the
  temperature in Landauer's bound" — recorded as reviewable data
  (`QUANTITY_IDENTIFICATIONS`), not buried in code.
- **Acceptance:** composed evaluator matches the closed form to
  relErr ≤ 1e−12 for M ∈ {M_sun, 10 M_sun, 10⁻⁸ M_sun}; the dimension
  functor confirms [temperature] at the junction and [energy] at the
  output; confidence(CT-1) = min(highly-speculative, speculative) =
  highly-speculative (the confidence algebra must demote, not average).
- Literature anchors: Hawking 1975 CMP 43:199; Landauer 1961 IBM JRD
  5:183. The composite is the standard erasure-cost-at-T_H expression.

**CT-1b — three-edge variant through a diagonal law (realizes P-1).**
`M → r_s` (LAW: Schwarzschild radius r_s = 2GM/c², GR diagonal) →
`r_s → T_H` (BE-42 re-parameterized: T_H = ℏc/(4π k_B r_s)) →
`T_H → E_min` (BE-16). **Acceptance:** 3-edge result ≡ 2-edge CT-1
result ≡ closed form (relErr ≤ 1e−12) — demonstrating laws as
connective tissue.

**CT-2 — weak-field consistency ratio (realizes Part-IX C5-adjacent).**
BE-51 (lensing α = 4GM/bc²) and BE-52 (perihelion Δφ = 6πGM/(a(1−e²)c²))
share source quantities (G, M, c); their quotient is parameter-free:

    α/Δφ = 2 a (1−e²) / (3π b)

- This is a *parallel* graph operation (shared-source consistency
  relation), not sequential composition — implemented as a distinct
  helper, honestly labeled.
- **Acceptance:** ratio computed from the two edge evaluators is
  independent of M across 3 orders of magnitude (relErr ≤ 1e−12) and
  equals the closed form.

## 3. Graph-lite design (T1–T3)

New directory `src/composition/` (file-disjoint from all existing code):

```ts
// quantity.ts
interface Quantity {
  name: string;             // canonical, e.g. 'temperature'
  symbol: string;           // display, e.g. 'T_H'
  dim: Dimension;           // from src/dimensional/types.js
  attributes: RegimeAttributes; // SPARSE — only what is known
}
type RegimeAttributes = Partial<{
  scale: 'quantum'|'mesoscopic'|'classical'|'cosmological';
  force: 'gravitational'|'electromagnetic'|'weak'|'strong'|'emergent';
  information: 'von-neumann'|'shannon'|'kolmogorov'|'discord';
  // symmetry/dimension/topology axes intentionally omitted until load-bearing
}>;

// edge.ts
interface ValidityDomain {           // G-8
  description: string;               // human-readable, e.g. 'M > 0 (positive mass)'
  predicate: (inputs: Record<string, number>) => boolean;
}
interface BridgeEdge {
  id: string;                        // e.g. 'be-42', 'law-schwarzschild-radius'
  beId: number | null;               // catalog cross-ref; null for laws
  kind: 'bridge' | 'law';            // P-1: laws are edges whose endpoints SHARE regime attributes
  sources: Quantity[];               // n-ary inputs
  target: Quantity;
  confidence: 'established' | 'speculative' | 'highly-speculative';
  domain: ValidityDomain;
  evaluate: (inputs: Record<string, number>) => number; // keys = source quantity names
  citation: string;
}

// compose.ts
interface QuantityIdentification {   // the reviewable physics judgments
  from: string; to: string;          // quantity names
  rationale: string; citation?: string;
}
compose(first: BridgeEdge, second: BridgeEdge, opts?): ComposedRelation
// defined iff: first.target identifies with one of second.sources
//   (same name, OR listed in QUANTITY_IDENTIFICATIONS) AND dims are
//   EXACTLY equal (the dimension-functor check — integer-vector
//   equality per the §19.3 exactness rule) AND domains are conjoinable.
// ComposedRelation: { edge: BridgeEdge } where
//   confidence = min(first, second) on the ordering
//     established > speculative > highly-speculative,
//   domain.predicate = first.domain ∧ (second.domain ∘ first)  — i.e.
//     second's domain is checked on the PIPED intermediate value,
//   evaluate = pipe first's output into second's matching input.
consistencyRatio(a: BridgeEdge, b: BridgeEdge, shared: string[]): …  // CT-2 helper
```

Decisions pinned:

- **D-1.** The junction check uses *exact* dimension equality (ℤ⁷
  integer-vector), reusing `Dimension` from `src/dimensional/types.js`
  and a local `dimEquals` (the existing algebra module is checked at
  implementation time for a reusable equality; if present, reuse).
- **D-2.** `compose()` returns a *new* `BridgeEdge`, so composition
  closes over the edge type and chains arbitrarily (CT-1b is
  `compose(compose(law, be42'), be16)`).
- **D-3.** Composition failures throw typed errors naming the reason
  (junction-mismatch / dimension-mismatch / domain-incompatible) — a
  failed composition must be diagnosable, per the improvement plan.
- **D-4.** Nothing in `src/core/` or `src/bridges/` is modified by
  T1–T4 except additive exports; the catalog stays authoritative.
- **D-5.** Domain conjunction composes *through* the pipe: the composed
  predicate evaluates `first` and checks `second`'s domain on the
  intermediate value. Document that this evaluates `first.evaluate`
  inside the predicate (acceptable for scalar closed forms; revisit if
  edges become expensive).

## 4. GW170817 confrontation design (T5)

New `src/bridges/be36-gw170817-confrontation.ts` + dataset record:

- Observation record (LIGO/Virgo + Fermi-GBM + INTEGRAL, ApJL 848:L13,
  2017): Δt = 1.74 ± 0.05 s (GW merger → GRB 170817A onset); luminosity
  distance D_L = 40 (+8/−14) Mpc; the paper's conservative speed bound
  uses the **lower** distance bound 26 Mpc and an assumed EM-emission
  delay ∈ [0, 10] s, yielding **−3×10⁻¹⁵ ≤ (c_GW − c)/c ≤ +7×10⁻¹⁶**.
- `confrontBE36(obs)` recomputes both bounds from (Δt, D, delay
  assumptions) via Δv/c ≈ c·Δt/D and compares against BE-36's encoded
  bound (≤ 10⁻¹⁵): returns `{ lowerBound, upperBound, passesEncodedBound,
  … }`.
- **Acceptance:** recomputed bounds reproduce the published −3×10⁻¹⁵ /
  +7×10⁻¹⁶ to ≤5% (they are 1-sig-fig published values); the result
  satisfies BE-36's encoded ≤10⁻¹⁵ on the positive side and documents
  the 3×10⁻¹⁵ negative side honestly (the encoded bound is the
  positive-side bound — verify against the BE-36 module text and note
  any needed docstring correction as a fix-along-the-way).

## 5. Membership criterion + adjudication (T6)

- **Criterion (graph-native, mechanical):** *a bridge is an edge whose
  endpoint quantities differ in at least one regime attribute; a law is
  an edge whose endpoints share all stated regime attributes.* For
  catalog entries (not yet graph-encoded) the `bridges: [a, b]` tuple is
  the proxy: `a ≠ b` (both known) → bridge; `a = b` → not-a-bridge;
  contains `'unknown'` → unadjudicated.
- New `src/bridges/membership.ts`: `adjudicateBridgeEntry(entry)` →
  `'bridge' | 'not-a-bridge' | 'unadjudicated'` + whole-catalog report.
- **Deferred decisions resolved by the criterion:**
  - **BE-42 Hawking T → BRIDGE (reversal of the audit-§3 classification).**
    Endpoints as quantities: M (classical/gravitational) → T_H
    (quantum — ℏ in the formula — thermal). Attributes differ in scale
    and force ⇒ bridge. Tuple updated `['unknown','unknown']` →
    `['gravity','quantum']` (matching BE-43's vocabulary). This is the
    outcome Adam argued for; the criterion makes it mechanical.
  - **BE-29 Jarzynski → NOT-A-BRIDGE (upheld).** ⟨e^(−βW)⟩ = e^(−βΔF)
    relates a nonequilibrium work distribution to an equilibrium free
    energy — both classical statistical-mechanics quantities; the
    distinction (equilibrium status) is not one of the regime axes.
    Recorded in the negative catalog; catalog entry keeps its tuple
    `['unknown','unknown']` but gains a notes pointer (additive).
  - The remaining `'unknown'` tuples are adjudicated by the same
    per-entry endpoint analysis where clear; left unadjudicated (with
    the reason) where genuinely contested. All outcomes land in the
    report doc `docs/architecture/v0.8.0-catalog-adjudication.md`.
- **P-4 negative catalog:** `src/bridges/rejected.ts` —
  `REJECTED_BRIDGE_ADJUDICATIONS: ReadonlyArray<{ beId, name, verdict:
  'not-a-bridge', reason, citation }>` + a consistency test (no id may
  be both rejected and tuple-adjudicated 'bridge').
- **Test-impact gate:** before editing any catalog tuple, grep tests for
  pins on that entry's `bridges` field; update pins in the same commit
  with the honest-deviation note.

## 9. CT-3 registration (C1; added 2026-06-11, BEFORE implementation)

**CT-3 — "Zurek decoherence scaling" (realizes Part-IX C1).**
Compose BE-12 (thermal de Broglie, `(m, T) → λ_T`) with BE-11's
Caldeira-Leggett quadratic-coupling rate (`γ₀·(λ/λ₀)²`) realized for
spatial superpositions — the physics judgment on record: *for a spatial
superposition of extent Δx in a thermal environment, BE-11's reference
coupling λ₀ IS the thermal de Broglie wavelength* (Zurek 1991 *Phys.
Today* 44(10):36, τ_D = τ_R·(λ_T/Δx)²; Zurek 2003 *RMP* 75:715 §III.E;
Caldeira & Leggett 1983 *Physica A* 121:587). Junction by NAME:
`thermal-de-broglie-wavelength`.

    Γ_dec(m, T, γ_relax, Δx) = γ_relax · Δx² · m k_B T / (2π ℏ²)

**Acceptance (registered before any code):**
1. `composeEdges(be12Edge, be11ZurekEdge)` matches the closed form
   above to relErr ≤ 1e−12 at three parameter sets spanning ≥6 decades
   of mass.
2. Zurek's classic macroscopicity anchor: for m = 1 g, T = 300 K,
   Δx = 1 cm, the enhancement Γ_dec/γ_relax = (Δx/λ_T)² lies in
   [10³⁹, 10⁴¹] (the famous "~10⁴⁰" — decoherence is fast).
3. Confidence demotes: established (BE-11) ∘ speculative (BE-12) →
   speculative.
4. Composed sources are exactly {mass, temperature, relaxation-rate,
   superposition-extent}; target dim [T⁻¹]; junction dim [L].

## 10. CT-4 registration (C5 completion; added 2026-06-11, BEFORE implementation)

**CT-4 — "weak-field cross-observable ratio" (completes Part-IX C5:
BE-37 ↔ BE-52).** Both observables are weak-field Schwarzschild
functionals of the same (G, M): Shapiro Δt = (2GM/c³)·ln(R_far/R_near)
and perihelion Δφ = 6πGM/(a(1−e²)c²). Their shared-source quotient is
parameter-free in the gravitating mass:

    Δt/Δφ = a(1−e²)·ln(R_far/R_near) / (3π c)    [seconds]

**Acceptance (registered before any code):**
1. `consistencyRatio(be37Edge, be52Edge, inputs)` is independent of M
   across ≥3 decades (relErr ≤ 1e−12) and equals the closed form.
2. Numerical anchor (solar values: a = 5.79e10 m, e = 0.2056,
   R_far = 1.496e11 m, R_near = 6.96e8 m): ratio =
   a(1−e²)ln(R_far/R_near)/(3πc) ≈ 1.066e2 s — assert within
   [1.0e2, 1.1e2] (sanity window) AND exact closed form.
3. be37Edge G-8 domain: M > 0 ∧ 0 < R_near ≤ R_far.
4. Both edges `established`; the ratio inherits no demotion concern
   (consistencyRatio is parallel, not sequential — no confidence
   algebra applies; documented).

Literature anchors: Shapiro 1964 PRL 13:789; Einstein 1915 (perihelion);
both already validated individually in-repo (BE-37 relErr ~2e-8 vs GL4,
BE-52 1.8e-7). The NOVELTY is the machine-checked parameter-free
cross-observable relation — Part-IX C5's "weak-field GR consistency
across observables" in exactly the catalog's own framing.
