## S-1 — Runtime-guard helper for `evaluateXxx()` across 42 BE modules

**Target:** 42 `src/bridges/equations/be-##-*.ts` modules. Every `evaluate*` function opens with 1–4 `Number.isFinite(x) || x <= 0` (or `< 0`) guards each throwing a verbose `RangeError`. Example cluster: `src/bridges/equations/be-37-shapiro-delay.ts:283-298` (Shapiro, 3 guards × 4 lines = 12 LOC), `src/bridges/equations/be-11-decoherence-master.ts:108-130` (~18 LOC), `src/bridges/equations/be-19-quantum-bounce.ts:161-181` (3 guards). Confirmed by `grep -l "if (!Number.isFinite" src/bridges/equations/*.ts | wc -l` → 42 files.

**Pattern:** Helper-extraction. New module `src/bridges/equations/_evaluator-guards.ts` (underscore-prefixed to signal "shared by siblings"):

```ts
export function requireFinitePositive(label: string, value: number, evaluator: string): void;
export function requireFiniteNonNegative(label: string, value: number, evaluator: string): void;
export function requireFinite(label: string, value: number, evaluator: string): void;
```

Each per-BE evaluator collapses from `if (!Number.isFinite(x) || x <= 0) throw new RangeError(...);` (4 lines) to `requireFinitePositive('M_kg', M_kg, 'evaluateShapiroDelay');` (1 line). The error-message vocabulary is preserved (the helper produces the same `"must be a finite positive number, got X"` text).

**Cost:** New file (~50 LOC); per-BE edits in 42 files; ~150 evaluator-input guards collapsed from 4 lines → 1 line each. Net: ~−300 to ~−450 LOC across `src/bridges/equations/`. Test churn: none — existing per-evaluator RangeError tests pass unchanged (string-pattern match preserved).

**Risk:** LOW. Behavior-preserving extraction; the existing error-message pattern is the test contract (consumers do `expect(() => evaluate(...)).toThrow(/must be finite/)`-style matchers — verify in `tests/bridges/`).

Citations: `src/bridges/equations/be-12-coherence-length.ts:74-85`, `src/bridges/equations/be-13-einstein-trace.ts:236-245`, `src/bridges/equations/be-16-landauer.ts`, `src/bridges/equations/be-21-kss-bound.ts`, etc.

**Cost:** 1 new helper (~10 LOC) + 29 file edits collapsing ~10 LOC each → ~3 LOC. Net: ~−150 LOC. Test churn: none (the `DimensionValidationReport` shape and the `ok`/`lhsDim`/`rhsDim` semantics are preserved bit-identically).

## S-13 — Three pattern-B validators (Ricci/Einstein/Bianchi) take identical `validateRiemannChild` callback

**Pattern:** Helper-extraction (collapse the parameter). Refactor the three pattern-B validators to import the canonical callback directly instead of taking it as a parameter:

```ts
// Before:

// After:
import { canonicalRiemannChildCallback } from './validator-registry.js';  // or move to a shared module
export function validateRicciTensor(node) {
  const rResult = canonicalRiemannChildCallback(node.riemann);
  ...

```

**Cost:** ~−12 to ~−20 LOC across `curvature.ts`. Net positive: removes the "what if the registry passes the wrong callback?" failure mode entirely.

## S-15 — `Float64ReferenceEngine.{add,sub,mul,scale}` AD-dispatch chains

**Target:** `src/numerical/float64-engine.ts:372-419` — four methods each open with a 6-line dual+taped+plain-fallback dispatch:

```ts
add(a, b) {
  if (a instanceof EngineDualTensor && b instanceof EngineDualTensor) {
    return a.add(b) as unknown as EngineTensor;
  }
  if (a instanceof EngineTapedTensor && b instanceof EngineTapedTensor) {
    return a.add(b) as unknown as EngineTensor;
  }
  return elementwise(asF64(a, 'add'), asF64(b, 'add'), 'add', (x, y) => x + y);
}
```

Same shape in `sub`, `mul`, `scale`. The `scale` arm is slightly different (unary).

**Pattern:** Discriminated-union dispatch via a helper:

```ts
function adDispatch<T extends EngineTensor>(
  a: EngineTensor, b: EngineTensor | undefined,
  op: 'add'|'sub'|'mul'|'scale',
  fallback: () => T,
): T {
  if (a instanceof EngineDualTensor && (b === undefined || b instanceof EngineDualTensor)) {
    return (b === undefined ? a[op]() : a[op](b as EngineDualTensor)) as unknown as T;
  }
  if (a instanceof EngineTapedTensor && (b === undefined || b instanceof EngineTapedTensor)) {
    return (b === undefined ? a[op]() : a[op](b as EngineTapedTensor)) as unknown as T;
  }
  return fallback();
}
```

Then each method becomes 1 expression.

**Cost:** ~−25 to ~−35 LOC; +10 LOC helper. Net: ~−20 LOC.

**Risk:** LOW. Behavior-preserving. TypeScript's structural-types on `EngineDualTensor.add(other: EngineDualTensor)` may resist the polymorphic `a[op]` indexing — fallback is a per-op dispatch object. Combine with S-11 (both touch float64-engine.ts).
