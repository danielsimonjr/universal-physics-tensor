### F1 (HIGH) — Phase A sequencing collision with P5

**Issue.** P6 design Decision #2 (line 110) names P5 as a hard
prerequisite, AND notes "v0.8 Phase A (in parallel)". §A.2 step 3

### F2 (MEDIUM) — Cascade evaluator needs translation layer that doesn't exist

**Issue.** `src/bridges/perihelion-precession.ts:43-56` returns
`PerihelionPrecessionResult` (6 numeric fields).
`src/bridges/gravitational-lensing.ts:38-47` returns
`GravitationalLensingResult`. These ad-hoc TS interfaces have no
shared `Observable` / `RegimeType` contract — B_A's output cannot
be wired into B_B's input without a hand-written adapter per pair.

**Resolution.** Phase A's optional `src/composition/` prototype
is SKIPPED per Adam-F2 — the translation layer design IS Phase B's
deliverable. Question Q1 in
`v0.7-Proposal-6-PhaseA-Open-Questions.md` captures the choice
between (a) shared `Observable` contract and (b) per-pair
`BridgeAdapter`.

### F3 (MEDIUM) — Categorical layer is documentation-only by design

**Issue.** Decision #5 of P6 design (lines 187-206) explicitly
makes the Baez/Stay/Coecke/Spivak framing "deliberately weak" and
"documentation-only in Phase A."

**Resolution.** ACCEPTED as-designed. `Part-IX-Composition.md` §3
documents the categorical framing as the LANGUAGE; no
`src/composition/category/` code ships in Phase A.

### F4 (LOW) — Two-axis framing (decoupled vs v0.8-bound) serves Phase A

**Issue.** The "decoupled from release" framing (line 38-41) and
"Phase A inside v0.8" framing (line 32) are mutually consistent if
Phase A contributes to v0.8 without gating it.

**Resolution.** Acknowledged. Phase A's docs ship in this session;
v0.8 tag (or rolled-into-v0.7) is the user's choice.
