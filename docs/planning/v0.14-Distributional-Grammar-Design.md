# v0.14 — Distributional / Variational Grammar Primitives (Design Note)

Implements the standing roadmap item "Grammar extensions for genuinely-deferred
primitives": two new scalar `ExprNode` arms that let the dimensional validator
EXPRESS the Model-A Langevin / fluctuation-dissipation relation the BE-15
docstring documents as un-encodable —

  ∂φ/∂t = −Γ δH/δφ + ζ ,   ⟨ζ(x,t)ζ(x',t')⟩ = 2Γk_BT δ(x−x') δ(t−t')

- **`dirac-delta`** — the Dirac-δ correlator primitive (barrier 1).
- **`variational-derivative`** — the functional derivative δF/δφ (barrier 2).

(Barrier 3, functional integration `H[φ] = ∫Dφ …` over field configurations, is
a measure over function space — NOT in scope; the roadmap names only the two
above.)

## The dimensional rules (the whole point)

Both are SCALAR-producing inline arms, exactly like the existing `integral` /
`derivative` arms (shape-guarded, `inferArgLocal` children, a pure dimensional
rule). They are NOT numerically evaluable (δ(0)=∞; a functional derivative needs
the functional's form) — `lowering` throws for them alongside `integral` /
`derivative`, and `evalExpr` / `substitute` fall to their throwing defaults.

1. **`{ kind: 'dirac-delta', arg: ExprNode }`** → `dim = power(dim(arg), −1)`.
   Because `∫ δ(x) dx = 1` (dimensionless) ⟹ `[δ(x)] = [x]⁻¹`. A dimensionless
   arg gives a dimensionless δ. Multi-argument deltas `δ(x)δ(t)` are an `op '*'`
   of single-arg `dirac-delta` nodes — no special multi-arg node needed.

2. **`{ kind: 'variational-derivative', functional, field, over }`** →
   `dim = divide(divide(dim(functional), dim(field)), dim(over))`, i.e.
   `[F]/([φ]·[μ])`. Because `δF = ∫ (δF/δφ) δφ dμ` ⟹
   `[F] = [δF/δφ]·[φ]·[μ]`. `over` carries the integration-measure dimension
   (the `dμ` whose one integration the variational derivative "undoes"),
   symmetric with `integral { integrand, over }` (which MULTIPLIES by `[over]`;
   this DIVIDES by it and by `[field]`).

Both arms are SCALAR: a child carrying free indices is rejected with
`TensorInScalarOpError` (mirroring the scalar `*`/`/`/`^` arms), and the node
contributes no free indices to the parent.

## Integration points (grounded against HEAD)

- `validator.ts`: add the two inline arms to the `ExprNode` union; add the two
  `case` arms to `infer` (the union has a `_exhaustive: never` default, so the
  arms are mandatory — the compiler enforces it). Update the header scope note
  (barriers 1+2 now expressible).
- `lowering.ts`: add `case 'dirac-delta'` / `case 'variational-derivative'` to
  the existing `integral`/`derivative` throw group (`NumericalBackendError`,
  "not numerically evaluated") — its `default` arm has a `never` exhaustiveness
  that would otherwise fail at tsc.
- `evalExpr` (expr-eval.ts), `substitute` (expr-subst.ts), `collectSymbols`
  (compose-symbolic.ts): throwing/`return` DEFAULT arms already tolerate new
  kinds — verified no `never` there. (These constructs never appear in a
  composable `symbolic` form, so the throw is correct.)
- The MathTS / Path-B formula transpilers BUILD ExprNode (don't switch on it) —
  unaffected.

## Public surface

The two arms are INLINE object types in the `ExprNode` union (like `integral` /
`derivative`), NOT named exported interfaces — so NO new entries in
`ALL_TYPE_EXPORTS` and NO runtime-snapshot change. Zero public-surface change.

## Demonstration (uncontested physics; catalog re-encoding deferred)

A test validates the FULL Model-A FDT relation, exercising both primitives, with
dimensions chosen consistently:
- `[φ]` a field dimension; `H` an energy `[F]=ENERGY`; the spatial measure
  `over = d³x` with `[μ]=L³`.
- `δH/δφ over d³x` → `ENERGY·[φ]⁻¹·L⁻³`.
- The Model-A Langevin `∂φ/∂t = −Γ·δH/δφ` fixes `[Γ] = [φ]²·L³·T⁻¹·ENERGY⁻¹`.
- FDT RHS `2·Γ·k_BT·δ³(x)·δ(t)` with `k_BT=ENERGY`, `δ³(x)=L⁻³`, `δ(t)=T⁻¹`
  then evaluates to `[φ]²·T⁻²` = `[ζ]²` = `[∂φ/∂t]²` — the LHS. **The FDT
  correlator equation is dimensionally homogeneous through the new grammar.**

The CATALOG re-encoding — replacing BE-15's deliberate Kawasaki-Gunton
`L²=Γt` reduction with the faithful Langevin form, and BE-28's contested Onsager
σ with a faithful MEPP variational maximization — is a PHYSICS-CURATION decision
(BE-28 in particular carries a ⚠ CRITICAL WARNING that its σ=ΣJX is the
definiendum, not the variational principle). That is a physicist's call
(CONTRIBUTING.md), deferred; this increment delivers the GRAMMAR + proves it
expresses the forms. BE-15's docstring is updated to record that barriers 1 and 2
are now lifted.

## Test plan

- `dirac-delta`: `δ(length)` → `[L]⁻¹`; `δ(time)` → `[T]⁻¹`; `δ(dimensionless)` →
  dimensionless; `δ(x)δ(t)` product → `[L]⁻¹[T]⁻¹`; missing `arg` → violation;
  tensor arg → throws.
- `variational-derivative`: `δH/δφ over d³x` → `[F]/[φ]/[μ]`; missing any field →
  violation; tensor child → throws.
- Equation-level: the full Model-A FDT relation validates homogeneous via
  `validateEquation` (the marquee).
- Regression: `validate`/`lowering` exhaustiveness compiles; full suite green.
