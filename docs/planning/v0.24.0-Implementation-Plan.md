## Task 2 — Monomial algebra (`src/composition/proposed-bridges.ts`, internal)

Two pure helpers over flat-monomial `ExprNode`s. **AST-level monomial gate**
(complements the L0 `monomial: null` gate): reject anything that is not a product
/ quotient / integer-power of symbols.

```ts
type Mono = Map<string, { dim: Dimension; exp: number }>;   // leaf → (dim, exponent)
class NotAMonomialError extends Error {}

function toMonomial(ast: ExprNode): Mono            // sym→{dim,+1}; '*' merges(+);
                                                    // '/'→merge(a, negate(b));
                                                    // '^'[base, intLiteral]→scale;
                                                    // else throw NotAMonomialError
function fromMonomial(m: Mono): ExprNode            // pos exps → numerator product,
                                                    // neg exps → denominator; pow for |exp|>1
```

TDD: `toMonomial(landauer.scalarAst)` = `{k_B:+1, T:+1, ln2:+1}`;
round-trips through `fromMonomial` to a dimensionally-equal AST;
`toMonomial(op('+', …))` throws `NotAMonomialError`.

## Task 3 — `deriveProposedBridges()` + `ProposedBridge` (the generator)

`ProposedBridge` interface exactly per Design §4 (status literal `'unadjudicated'`;
omits every physics-judgment field; `derivedFrom`, `target`, `governing`,
`formulaLatex`, `scalarAst`, `dimensionalSignature`, `provenance`, `evaluate`).

Algorithm (Design §5, v2):
```ts
export function deriveProposedBridges(
  candidates = rankDiscoveries(CANONICAL_GRAPH),
): readonly ProposedBridge[] {
  out = []
  for cand in candidates where verdict==='promising':
    [t0, t1] = [cand.a, cand.b].sort()                 // endpoint-sorted (m6)
    [E1, E2] = [unique(canonicalByTarget(t0)), unique(canonicalByTarget(t1))]
    if !E1 || !E2: continue                              // ambiguous/missing → skip (E1)
    if E1.monomial==null || E2.monomial==null: continue // gate 1 (determinacy)
    if E1.epistemicStatus!=='fully-quantitative'
       || E2.epistemicStatus!=='fully-quantitative': continue  // gate 2 (Jarzynski out)
    if !E1.scalarAst || !E2.scalarAst: continue
    m1 = toMonomial(E1.scalarAst); m2 = toMonomial(E2.scalarAst)   // may throw → skip
    solveFor = uniqueNonConstantLeaf(m2)                // ∉ CONSTANTS; exactly 1 else skip
    if solveFor ∈ m1: continue                          // degenerate overlap (§5.2)
    e = m2.get(solveFor).exp
    result = scale(merge(m1 /*+*/, negate(without(m2, solveFor))), 1/e)
    ast = fromMonomial(result)
    dim = validate(ast).inferredDimension
    if !dim || !equals(dim, solveFor.dim): continue     // round-trip guard (never fires for pilot)
    out.push(makeProposal(cand, [E1.id,E2.id], solveFor, ast, dim))
  return out
}
```
`uniqueNonConstantLeaf(m)` = the single leaf of `m` whose name ∉ `CONSTANTS`;
returns null if 0 or >1 (skip). For pilot `m2`=planck-einstein → `nu` (h is const).

`makeProposal`:
- `id = 'IC-' + [t0,t1].join('--') + '--' + solveFor`
- `formulaLatex` from `fromMonomial` (simple `\frac{num}{den}` builder)
- `provenance`: mechanical string — "Derived by monomial elimination of the
  identification {a}≡{b} between {E1}/{E2}; solved for {solveFor}. Algebraic
  consequence of an UNADJUDICATED identification — not a new physical relation.
  Governing-name map: {T→temperature}." + invertibleAs note
- `evaluate(values) = evalExpr(ast, values)` (constants auto-resolve; require the
  free non-constant leaves, here `T`)
- `status: 'unadjudicated'`

## Task 4 — `promoteProposal` gate (Design guardrail #5, Adam m5)

```ts
export interface PromotionEvidence {
  readonly citation: string;       // literature anchor
  readonly status: BridgeEquationStatus;   // human-chosen, NOT defaulted
  readonly reviewRef: string;      // path to the adversarial+literature review
}
/** Build a review-ready promotion REQUEST. Throws if any human input is missing
 *  or blank — operationalizes "null, not guessed". Does NOT write the catalog. */
export function promoteProposal(p: ProposedBridge, ev: PromotionEvidence): PromotionRequest
```
Returns a `{ proposal, evidence }` record (the artifact a human turns into a
catalog entry); throws `MissingEvidenceError` on empty `citation`/`reviewRef` or
absent `status`. TDD: throws on `{citation:''}`; returns the record on full input.
Deliberately stops short of synthesizing a `BridgeEquationEntry` (its physics-
judgment fields are human work).
