### Eve implementation-blockers
- **E1 (HIGH):** `canonicalByTarget()` does NOT exist — registry exposes only
  `canonicalById`/`canonicalByDomain`. Must add it; handle a target mapping to >1 CE.
- **E2 (HIGH):** symbol-name split — `dimensional.governing`/`monomial` key
  temperature as **`temperature`**; `scalarAst` leaf is **`T`**. A generator that
  reads solve-targets from `dimensional.*` but builds the AST from `scalarAst`
  will emit a proposal whose `governing`/`solvedFor` name disagrees with its
  `scalarAst`/`evaluate` leaf. Pick ONE convention and normalize.
- **E3 (LOW):** the Jarzynski proposal's prefactor is the non-constant stub
  `ln_avg_exp_minus_betaW` → its `evaluate` would demand that as a free input; the
  §7 "finite ~10¹² Hz" assertion doesn't account for it. (Subsumed by Adam S1/M3.)

## Adam — adversarial design/physics

- **S1 (SHOWSTOPPER):** the design names `dimensional.monomial` as the derivation
  engine (§2.1) but the headline output carries `ln2`, which monomials *cannot*
  supply ("the constant is NOT supplied — dimensional analysis cannot",
  `buckingham.ts:320-323`). The `ln2` exists only in `scalarAst`. The two engines
  are conflated. If `scalarAst` is the engine, the "monomial division is trivial"
  justification collapses for Jarzynski, whose `scalarAst` prefactor is a
  non-constant operator-valued stub.
- **S2 (overclaim):** "a new relation the catalog did not previously state" (§2)
  is false — eliminating a shared quantity between two known equations yields an
  algebraic *restatement*, not new physical content. The design concedes this
  ("equivalent rearrangements", §5.1) yet sells it as authoring bridges. Reframe.
- **M1:** the two pilots are duplicates — Landauer and Jarzynski share governing
  `{k_B, temperature}`, so both eliminate to the same `ν = const·(k_B/h)·T`.
- **M2:** §5.1 "one proposal per free non-constant variable" double-counts inverse
  forms (`ν=f(T)` and `T=f(ν)` are one relation).
- **M3:** the monomial-only scope admits Jarzynski (monomial *dimensionally*) then
  S1 bites; add a gate on a non-constant dimensionless prefactor —
  `epistemicStatus` is the ready discriminator (CE-jarzynski is
  `scalar-up-to-constant`, not `fully-quantitative`).
- **m4:** §7 no-catalog-write test checks `.length` (not identity) — assert array
  reference identity + content hash. Graph-feedback non-coercion should be
  guardrail #7, not an open question.
- **m5:** make `promoteProposal({citation,status,reviewRef})` (fails without them)
  a decision, not an open question.
- **m6:** ID `PB-<a>--<b>` must include `solvedFor` and sort endpoints, else the
  inverse forms collide.
- **m7:** worked example uses `T`; governing name is `temperature` (= E2).
