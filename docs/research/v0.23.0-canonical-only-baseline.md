## Why a canonical-only baseline

The discovery loop is normally run over the bridge catalog, where a `promising`
verdict is interesting *because* the bridge is speculative. Running it over the
**canonical L-layer instead** answers a different, calibrating question: when the
inputs are all established physics, does the funnel stay quiet, and is its
residual signal explicable? Two properties are load-bearing:

- **No contradiction must appear.** Standard physics is mutually consistent, so
  `contradictory = 0` is the pass condition. Any non-zero count would indict the
  engine, not the physics.
- **The promising/clash residue must be interpretable.** Whatever survives the
  funnel should be a recognisable dimensional coincidence or a real scale
  incompatibility — never a namespace or anchor artifact.

This run is also the regression surface for two fixes and one declared link
applied 2026-06-18 (see *Provenance* below); the numbers here are the
post-fix steady state.

## Provenance — fixes folded into this baseline (2026-06-18)

This baseline reflects three changes made the same day (branch
`claude/upt-analysis-no-bridge-kduiw0`), each surfaced by an earlier run of this
very analysis:

1. **Magnitude-gate sourcing.** Added sourced CODATA representative values for
   `compton-wavelength` (2.43e-12 m) and `bohr-radius` (5.29e-11 m) so the gate
   compares real magnitudes instead of falling back to the M_⊙ anchor. Killed the
   false `compton ≟ bohr` clash; kept the genuine Planck-scale clashes.
2. **Canonical name unification.** `T → temperature`, `M → mass`, Newton
   `m_1`/`m_2` → `mass`/`secondary-mass` (not both `mass`: `buckinghamPi`
   requires unique governing names, and the two distinct masses are Newton's
   free mass-ratio). De-fragmented the map (14 → 11 components; anchored cluster
   8 → 16 edges) and removed the `mass ≟ m_1`/`m_2`, `temperature ≟ T` namespace
   artifacts.
3. **Declared compton↔de-Broglie link.** Registered
   `de-broglie-wavelength → compton-wavelength` in `QUANTITY_IDENTIFICATIONS`:
   the Compton wavelength is the de Broglie wavelength at the relativistic limit
   `p = mc`, so at the graph's quantity-KIND resolution they name one matter-
   wavelength node. Folded onto `compton-wavelength` (the anchor-determinable,
   sourced node) so the genuine `planck-length ≟ compton-wavelength` clash
   survives. Moves the correspondence from a re-discovered `promising` candidate
   to a declared link.

Net effect across the three: discovery candidates 66 → 33, promising 8 → 2,
false clashes 1 → 0, contradictions 0 → 0 throughout.
